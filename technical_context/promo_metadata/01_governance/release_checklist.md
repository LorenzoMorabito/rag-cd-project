# Release Checklist

Before merging this package into the master corpus, validate:
1. owner assignment for each object
2. approval of user-facing dimension names
3. confirmation of which survey-style dimensions stay visible vs hidden
4. decision on how to handle `d_reconstructed_markets`
5. decision on null handling for `CONVERTED_CONTACTS`
6. approval of merge rules against the business glossary corpus
7. explicit policy for `MON / MQTR / QTR` promo measures
