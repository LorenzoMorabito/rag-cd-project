# Quality Index

## Canonical definition
This value is based on the answers to the "Quality of the contact" question: The sum of all these "+5", "0" and "-5" mentions needs to be divided by the total number of mentions for getting the "Quality Index" which is a value between -5 and +5

## Allowed values / key options
- The "+5" value corresponds to the "Very useful..." mentions
- The "0" value corresponds to the "Somewhat useful..." mentions
- The "-5" value corresponds to the "Not at all useful..." mentions
