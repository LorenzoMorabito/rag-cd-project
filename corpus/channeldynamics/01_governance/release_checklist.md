# Release checklist

A knowledge object should not move from `draft` to `approved` until all checks are complete.

## Mandatory checks
- use case is explicit
- title is informative and interrogable
- definition can be understood without previous paragraphs
- source provenance is present
- owner is assigned
- status and version are assigned
- duplicates against existing corpus are checked
- tables or examples have a text summary
- benchmark questions can retrieve the correct file
- ambiguous or unconfirmed content is not mixed with approved content

## Corpus-level checks
- answerability coverage meets internal target
- metadata completeness meets internal target
- traceability meets internal target
- deprecated content is separated from approved content
- retrieval settings are tested on benchmark questions
